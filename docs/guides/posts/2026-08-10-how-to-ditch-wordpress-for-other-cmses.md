WordPress is one of the most popular CMSes out here, and it's running a majority of the web. Back then, people told you to get your LAMP stack working on a host or use a free host and create your website on WordPress.

Now? WordPress is still widely used, but now it's not on a good spot on the community and it has been pushing more and more annoying problems for new users.

### But don't worry, you can ditch WordPress easily, if you have reasons to switch from it.

### Workflow

If you don't like WordPress' workflows like Gutenberg, the admin panel,...etc. A simpler CMS or plain HTML makes sense to you because it's less "I need maintenance" and more "get your site working and maybe forget about it in 5 years".

For the editor, you might like using Markdown better than using Gutenberg, yes, Gutenberg also has Markdown-style support, but it's not very close to actual Markdown. And I agree that Markdown is way way superior than using block editors for blogging.

### Maintenance

If you hate maintaining a WordPress site, then it's reasonable to switch to flat-file CMSes or HTML.

### Out of the box

If WordPress is not powerful enough out of the box. You might use something like Joomla!
